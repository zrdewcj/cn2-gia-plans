## CN2 GIA 和 CN2 GIA-E 有什么区别？

3. **价格**：同样的 CN2 GIA 级别回程，洛杉矶的价格只是香港的零头。官方自己也建议，如果不是对延迟特别敏感，优先考虑洛杉矶电商套餐。

### DC6 和 DC9 有什么不一样

GIA-E 系列里最常被拿来比较的是两个洛杉矶机房。DC6 是经典款，三网 CN2 GIA 回程，2.5Gbps 基线带宽，网上流传的“158ms、零丢包”测试数据大多出自它。DC9（USCA_9）是更新的机房，官方对它的描述是整体网络容量与稳定性最好，中国方向流量同时交给三家运营商：电信 CN2 GIA（AS4809）、移动 CMIN2（AS58807）、联通精品网（AS10099）。

这个三出口设计有实际意义。2019 年中国电信停止了与联通、移动在中美方向的对等互联，跨网流量要绕远路，如果你的访客里移动、联通用户不少，DC9 的多运营商出口能绕开一大块这种麻烦。买 GIA-E 之后，两边的差异可以自己迁移体验，反正不丢数据。

## 常见问题

**CN2 GIA 和 CN2 GT 有什么区别？**
两者都在电信 AS4809 骨干上，但服务等级不同。GT 当年是 163 拥堵的解决方案，价格贵很多，2019 年之后晚高峰基本堵回了 163 的水平；GIA 是端到端优化的最高档，稳定性最好，搬瓦工香港和日本套餐用的就是这一档（外加等同级别的 CTGNet）。

**晚高峰真实表现如何？**
从公开的第三方测试数据看，洛杉矶 GIA-E 从国内家宽环境测得的平均延迟在 158ms 上下，晚高峰丢包接近零；香港 30–60ms；东京 40–90ms。作为对比，普通 163 线路同一时段延迟 200–400ms 起步，丢包能上两位数——差距主要就体现在晚上八点到十二点。

**被 DDoS 攻击了会怎样？**
被攻击的 IP 会被临时空路由，期间服务不可用，攻击结束后恢复。GIA 线路不提供攻击清洗能力，这是它和普通线路在安全策略上的本质区别。

**买错机房能换吗？**
CN2 GIA-E 系列可以，支持在 11 个以上机房免费迁移且数据不丢；香港、东京等亚洲独立线路固定城市，不能这么换。拿不准的话，先买 GIA-E 再实际体验是风险最低的路径。
